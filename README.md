# HR Employee Attrition Dashboard

## Objective

To analyze employee attrition patterns using interactive visualizations in Power BI.

## Features

* Employee count by department
* Attrition analysis by department and job role
* Interactive slicers/filters
* Visual dashboard insights

## Tools Used

* Power BI
* Data Visualization
* GitHub

## Outcome

The dashboard helps identify employee attrition trends and provides insights for better workforce analysis and decision-making.
